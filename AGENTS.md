# AGENTS.md

Instructions for AI coding agents (Codex, Cursor, Copilot, Gemini, Claude and others) live in
[CLAUDE.md](CLAUDE.md): build and test commands, the architecture map, the security invariants and the
conventions. Read it before changing code.

To **use** Umbra from an agent rather than change it, run the MCP server: `umbractl mcp`
(see the README section "Automate Umbra"). To **write a widget**, read [docs/widget-sdk.md](docs/widget-sdk.md).
