Sandboxed

Every widget gets a locked room.

  • Only the hosts it declares. A widget reaches the HTTPS hosts listed in its widget.json. Every other request gets a 403 from the host app.
  • No silent upgrades. An update that asks for new hosts, notifications, media or commands waits until you accept it.
  • Commands, only with your OK. A widget can run a local program only if it declared that exact command, with no shell, and you approved it.
